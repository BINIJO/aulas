Módulo 1
O que é um algoritmo?

Antes de qualquer linha de código, você precisa entender o que é um algoritmo. Spoiler: você já usa algoritmos todo dia sem perceber.

📋 Definição simples

Um algoritmo é uma sequência de passos ordenados e claros que resolve um problema específico. Todo algoritmo tem começo, meio e fim.

Analogia da receita: Fazer arroz é um algoritmo. Você segue passos em ordem: medir o arroz → lavar → refogar → adicionar água → tampar → aguardar. Se mudar a ordem ou pular um passo, dá errado. Programas funcionam da mesma forma.
✅ As 3 características fundamentais
1

Tem início e fim definidos

Todo algoritmo começa em um ponto e termina. Não pode ficar rodando eternamente (ou se rodar, é intencional).

2

Passos claros e sem ambiguidade

"Misture bastante" é vago. "Misture por 3 minutos na velocidade média" é um passo de algoritmo. Computadores são literais — cada instrução precisa ser exata.

3

Produz sempre um resultado

Ao final, algo acontece: um número foi calculado, uma lista foi ordenada, um arquivo foi salvo. Sem resultado = não é algoritmo.

📝 Pseudocódigo — escrevendo antes do código

Antes de codificar, escrevemos o algoritmo em linguagem humana estruturada. Isso ajuda a pensar a lógica sem se preocupar com a sintaxe de uma linguagem:

// Algoritmo: Verificar se pode entrar na balada INÍCIO LEIA idade SE (idade >= 18) ENTÃO ESCREVA("Pode entrar!") SENÃO ESCREVA("Proibido. Menores não entram.") FIM SE FIM

Note: tem início, tem fim, tem uma decisão (SE) e passos bem definidos. Isso é a essência da programação.

Módulo 2
Variáveis e tipos de dados

Programas precisam guardar informações durante a execução. Para isso usamos variáveis — como caixas com etiqueta na memória do computador.

📦 O que é uma variável?

Uma variável é um espaço reservado na memória com um nome que você escolhe. Você pode guardar um valor, ler quando precisar, ou alterar a qualquer momento.

Analogia da caixa: Imagine uma caixa com uma etiqueta escrita "nome". Você pode colocar "João" dentro, abrir para ver, ou trocar por "Maria". A etiqueta é o nome da variável; o conteúdo é o valor.
🔢 Os 4 tipos de dados mais comuns
Inteiro (int)
Números sem vírgula, positivos ou negativos
idade = 25
Decimal (float)
Números com vírgula (usa ponto no código)
preco = 29.90
Texto (string)
Qualquer texto, sempre entre aspas
nome = "João"
Lógico (boolean)
Apenas verdadeiro ou falso
logado = verdadeiro
💡 Operações com variáveis
// Declarando variáveis nome = "Ana" idade = 20 altura = 1.68 // Operações matemáticas anoNascimento = 2024 - idade // resultado: 2004 idadeDobroDaAltura = idade + altura // 21.68 // Exibindo na tela ESCREVA("Olá, " + nome) ESCREVA("Nascida em: " + anoNascimento)

Módulo 3
Condições — SE / SENÃO

Programas precisam tomar decisões. A estrutura SE/SENÃO é o coração da lógica de programação — ela permite executar caminhos diferentes dependendo de uma condição.

🔀 A estrutura condicional

Funciona assim: SE uma condição for verdadeira, faz uma coisa. SENÃO, faz outra. Simples assim.

Analogia: Você chega num cruzamento. SE o semáforo estiver verde, atravessa. SENÃO, espera. Seu cérebro faz isso automaticamente — você está programando o mesmo tipo de lógica.
📝 Sintaxe e exemplo
// Estrutura básica SE (condição) ENTÃO // o que fazer quando verdadeiro SENÃO // o que fazer quando falso FIM SE
// Exemplo: sistema de notas nota = 7.5 SE (nota >= 7) ENTÃO ESCREVA("✓ Aprovado!") SENÃO SE (nota >= 5) ENTÃO ESCREVA("⚠ Recuperação") SENÃO ESCREVA("✗ Reprovado") FIM SE

Módulo 4
Repetição — Laços (loops)

Repetição é um dos superpoderes da programação. Com um laço você pode executar uma tarefa mil vezes sem reescrever o código mil vezes.

🔄 O que é um laço?

Um laço (loop) repete um bloco de código várias vezes — até que uma condição seja atendida, ou por um número definido de repetições.

Analogia: Você tem 20 e-mails para responder. O algoritmo seria: PARA cada e-mail na lista: ler o e-mail → escrever resposta → enviar. Repete 20 vezes sem você ter que escrever esse processo 20 vezes.
🔂 Tipo 1: PARA (for) — quantidade definida

Use quando você sabe exatamente quantas vezes vai repetir:

// Contar de 1 até 5 PARA i DE 1 ATÉ 5 FAÇA ESCREVA("Número: " + i) FIM PARA // Saída: // Número: 1 // Número: 2 // Número: 3 // Número: 4 // Número: 5
🔁 Tipo 2: ENQUANTO (while) — condição

Use quando não sabe quantas repetições serão necessárias, mas sabe quando parar:

// Continua pedindo senha até acertar senhaCorreta = "1234" tentativa = "" contador = 0 ENQUANTO (tentativa != senhaCorreta) FAÇA tentativa = LEIA("Digite a senha: ") contador = contador + 1 FIM ENQUANTO ESCREVA("Acesso liberado em " + contador + " tentativa(s)")

Módulo 5
Fluxogramas

Fluxogramas são mapas visuais de algoritmos. Antes de codar, muitos programadores desenham o fluxograma para pensar a lógica com clareza.

🗺️ Os símbolos principais
📊 Exemplo completo: verificar maioridade
💡 Como usar fluxogramas na prática
1

Entenda o problema

Antes de qualquer coisa, leia o problema com atenção. Quais são as entradas? O que o programa deve fazer? Quais saídas espera?

2

Desenhe no papel

Use papel e lápis. Comece pelo oval de início, liste os processos e identifique os pontos de decisão (losango).

3

Converta em pseudocódigo

Com o fluxograma pronto, converta para pseudocódigo. Cada símbolo vira uma linha: oval = INÍCIO/FIM, losango = SE, retângulo = instrução.

4

Escreva o código real

Por último, converta o pseudocódigo para a linguagem que vai usar (Python, JavaScript, etc.). A lógica já está resolvida — só muda a sintaxe.
